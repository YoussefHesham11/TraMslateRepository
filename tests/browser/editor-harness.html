    More tools

    Shift timing

    Enter the amount as HH:MM:SS:FF (frames use the fps selector above), HH:MM:SS, MM:SS, or plain seconds, then pick Earlier or Later — handy when the whole track has drifted out of sync with the video. A shift that would cross 00:00:00 or 24:00:00 is trimmed to the farthest safe point rather than blocked. "Zero out timing" rebases every cue so the earliest one starts at 00:00:00 — useful for scripts timed against a 1-hour broadcast offset. Cue numbers refer to the # shown on each card.

    More timing tools

    SRT, VTT and ASS files store real times: the fps selector never moves them — it only sets how frames are counted and how frame-based scripts (HH:MM:SS:FF) are read. To re-time for a video that runs at another speed, use Convert frame rate.
